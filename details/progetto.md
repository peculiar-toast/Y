# Progetto: Y
Social media.

## Descrizione
Social media con soli messaggi vocali.
Gli audio possono avere trascrizioni generati dagli utenti o automaticamente.

## Target
Rivolto a qualsiasi utente, vedente o non vedente.

## Mission
Creare un social media basato su messaggi vocali.

## Requirements

a. Ogni utente deve avere un account.
b. Ogni utente può creare post.
c. Ogni utente può vedere post in un feed.
d. Ogni utente può cercare post tramite barra di ricerca.

## Architettura Software
Web app in React, con API REST e backend Spring con database PostgreSQL.
